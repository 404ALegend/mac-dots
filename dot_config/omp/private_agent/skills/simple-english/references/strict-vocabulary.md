# Strict mode: the dictionary discipline

Read this file when the user names STE, ASD-STE100, or compliance. Strict mode adds the dictionary rules to the document. It does not change the reply to the user, which stays in Plain mode.

The official dictionary is copyrighted by ASD and is not reproduced here. Tell the user once that this index is lossy and full compliance needs the official dictionary at asd-ste100.org.

## Rules that exist only with the dictionary

| Rule | Instruction |
|---|---|
| 1.1 | Use only approved words, technical nouns, or technical verbs. |
| 1.2 | Use an approved word only as its listed part of speech. |
| 1.3 | Use an approved word only with its approved meaning. |
| 1.4 | Use only the approved forms of verbs and adjectives. |
| 1.6 | Use an unapproved word only when it is a technical noun or part of one. |
| 3.1 | Use only the verb forms that the dictionary gives. |
| 9.2 | Use each approved word correctly: approved meaning, approved part of speech. |
| GR-5 | Avoid false friends. |
| GR-8 | Use the possessive apostrophe only when you are sure that it is correct. |

## Part-of-speech rulings

| Word | Ruling |
|---|---|
| test, check, work | Noun only. Write "Do a test", not "test the pump". |
| oil | Technical noun only. For the verb, write "lubricate". |
| help | Verb only. For the noun, write "aid". |
| fall | Use as a verb only for movement downward by gravity. |
| follow | Means "come after", never "obey". |
| above, below | Physical positions only. For limits write "more than" or "less than". |

## Dictionary rulings on common software verbs

| You wrote | Use instead |
|---|---|
| check, verify, confirm, ensure | `make sure that`, `examine`, `measure`, or `do a check of`, by intent. |
| validate | A technical verb, or `make sure that`. |
| delete, drop, destroy | `erase` for data, `remove` for physical items. `delete` is legal as a computer technical verb. |
| remove | Keep it. |
| run, execute | `operate` for run, `do` for execute. |
| invoke, launch | Legal technical verbs. |
| display, render, present | `show`, `make`, `give`, or `show`, by intent. |
| issue | A technical noun, or `problem`. |
| failure | A technical noun only for performance loss. |
| error, problem | Keep them. |

## Recurring errors

| You wrote | STE writes |
|---|---|
| however | but |
| therefore | thus, as a result |
| since (= because) | because |
| any | Delete it, or restructure. |
| now | Delete it, or write "at this time". |
| need to, have to | Imperative in procedures, or "it is necessary to" in descriptive text. |
| perform | do |
| insert | put, except quoted SQL `INSERT`. |
| reach | get, get to |
| avoid | prevent |
| repeat | do again |
| acceptable | permitted, or state the limit. |
| complete (adjective) | completed |
| the example below, the section above | Name the target, or put the reference after it. |

## Strict self-check

2. Search for phrasal verbs such as "set up" and "go down". Replace each with a one-word verb.
